Limpar dados de teste deste navegador

Use antes do evento, nos aparelhos em que você testou o site. Só apaga os dados deste navegador, nunca os de outras pessoas nem os do banco.

  • Check-ins, avaliações, nome e favoritos guardados aqui
  • O usuário anônimo do Firebase (o navegador vira uma pessoa nova)
  • Caches e service worker do site

Não apaga os documentos do Firestore. Para isso use o workflow "Purge test data" no GitHub.
